# Bowditch 摆（Y 形摆）—— 交互式模拟器

面向 **IYPT 2027 第 5 题（Y 形摆 / Bowditch pendulum）** 的交互式物理模拟与演示程序。

装置是这样一个结构：两根长为 `l` 的上臂挂在水平相距 `2R` 的固定锚点上，在结点汇合，
再由一根长为 `L` 的下臂挂住摆球。从一角释放后，摆球不会沿直线往复，而是画出一个缓慢
旋进的 Lissajous 图案。本程序实时动画演示这套运动、同步画出摆球走过的图案，并允许用
滑条改动每一个几何参数、立刻看到图案如何变化。

这里没有预制动画：两个简正模的频率、振幅非线性、模间耦合以及结点质量的影响，全部由
下面描述的模型实时算出。

## 文件清单

| 文件 | 作用 |
|---|---|

## 物理模型

### 两个解耦的水平模

摆球的水平运动可以分解为面内分量 `x`（两根上臂所在平面内）与面外分量 `y`。在主体
的"系结"构型下，两个模的有效摆长不同，因而频率不同：

```
h     = sqrt(l^2 - R^2)                  结点在天花板以下的深度
f_in  = (1/2*pi) * sqrt(g / L)           面内模（有效摆长 L）
f_out = (1/2*pi) * sqrt(g / (L + h))     面外模（有效摆长 L + h）
f_r   = f_in / f_out = sqrt(1 + h / L)
```

全项目统一取 `g = 9.79324 m/s^2`。

### 为什么面内模严格就是摆长 `L` 的单摆

结点被系住时，它的约束圆整条落在 `X = 0` 平面内 —— 也就是两个锚点所在的平面 —— 因此
结点**没有面内自由度**。面内运动下，下臂就是一根长为 `L` 的单摆。面外运动时结点确实会
动，该简正模的有效摆长为 `L + h`，其中 `h = sqrt(l^2 - R^2)` 是结点在天花板以下的深度，
由两根长 `l`、锚点在 `±R` 的上臂决定。

### 振幅修正

精确单摆的振幅越大、周期越长。模拟器采用椭圆积分展开

```
T(A)/T_0 = 1 + A^2/(16 l^2) + 11 A^4/(3072 l^4)
   <=>   f(A)/f_0 = 1 - A^2/(16 l^2) - 11 A^4/(3072 l^4)
```

并把它反解成引擎加速度表达式里的 Duffing 系数（`a = 1/(6 l^2)`、
`b = (16/5) * 11/(3072 l^4)`，两个模各自代入自己的有效摆长）。两个模都随振幅变慢，
面内模变慢更多，于是拍周期变长。`--selftest` 在 `A = 50 mm` 处复现该律到约 `7e-7`
相对偏差（自检自身的门限是 `5e-4`）。

### 结点质量

记 `mu = m_K / m`、`a = h / (L + h)`，结点质量的影响是不对称的：

* **`f_in` 与 `mu` 严格无关** —— 结点没有面内自由度，它的惯性加不到面内模上；
* **`f_out` 随 `mu` 升高**，规律是 `sqrt((1 + mu*a) / (1 + mu*a^2))`。

在参考几何下，`mu = 0.01` 会把 `f_r` 拉低约 0.12%（降到 `1.3433`）—— 所以结点质量必须
标定，不能忽略。

### 松弛阈值

`x_c = R * L / h` 是释放振幅的上限：超过它，一根上臂会松弛，模型不再成立（参考几何下为
`0.0742 m`）。界面会在释放振幅超过该值时给出警告。

### 模间耦合

引擎加入了 `x^2 y^2` 耦合项，其系数（`0.420`）由**完整非线性动力学的直接数值积分**标定：
等振幅释放时，拍周期必须复现 `4.291994`、`4.305508`、`4.327382 s`，对应 `A` = 20、40、
60 mm。`--selftest` 会由模型反算 `T_beat` 并与这三个值逐一核对。

## 参考数值

在项目的参考几何 `l = 0.250 m`、`R = 0.060 m`、`L = 0.300 m` 下（无质量结点）：

| 量 | 数值 |
|---|---|
| `h = sqrt(l^2 - R^2)` | `0.242693 m` |
| `f_in = (1/2*pi) * sqrt(g/L)` | `0.909332 Hz` |
| `f_out = (1/2*pi) * sqrt(g/(L+h))` | `0.676093 Hz` |
| `f_r = f_in / f_out = sqrt(1 + h/L)` | `1.344982` |
| `x_c = R * L / h` | `0.0742 m` |

界面默认结点质量为 `0.2 g`（`mu = 0.002`）时，同一几何给出 `f_out = 0.676260 Hz`、
`f_r = 1.344650`。

只改结点处的机械约束，图案就完全不同：

| 结点约束 | 参考几何下的 `f_r` | 行为 |
|---|---|---|
| 系结（主装置） | `1.344982`（无质量结点），`0.2 g` 时 `1.344650` | 图案旋进；拍周期约 4.3 s |
| 滑环 | `1.013574` | 两模近简并；旋进需要上百秒 |
| 三弦三脚架 | 严格 `1.000000` | 严格简并；图案永不旋进 |

## 功能

**两个标签页。**

* **标签页 1 —— 动画与二维轨迹同屏。** 三个面板共享同一份模拟状态：最大的下视
  Lissajous 轨迹、显示 `|x(t)|` 与 `|y(t)|`（也就是"拍"）的包络面板，以及真实装置的
  侧视动画（两根上臂、结点、下臂、带余辉的摆球）。三块画布用 grid 权重按比例分配，
  窗口缩放时保持比例，不会把任何一块挤没。
* **标签页 2 —— 可旋转的 3D 视图。** 按住左键拖动旋转（方位角自由，仰角限制在
  `±88°`），滚轮缩放（每格 `1.15` 倍，限幅 `0.2x`–`8.0x`），双击复位到方位角 `38°`、
  仰角 `24°`。可选缓慢自动旋转，以及可开关的三维轨迹。

**8 个参数滑条：** 上臂长 `l`（0.100–0.800 m）、孔距半值 `R`（0.005–0.300 m）、下臂长
`L`（0.050–0.900 m）、结点质量 `m_K`（0–5.0 g）、释放振幅 `A`（0.002–0.150 m）、释放
方位 `psi_0`（0–90°）、阻尼 `b`（0–0.200 1/s）、时间倍率（0.1–3.0x，只改变播放速度，
不改变物理）。另有 4 组预设（参考几何、1:1 简并、宽 V 形、短下臂），以及播放/暂停、
重新释放、清轨迹、保存轨迹 PNG。

**三种结点约束模式：** 系结、滑环、三弦三脚架（见上表）。

**中英双语界面。** 控制面板顶部的 `语言 / Language` 一栏可以在运行时切换所有标签、
按钮、标签页标题与画布内文字——**包括当前不可见的画布**。默认跟随系统区域（中文系统给
中文，其余给英文），也可以用 `--lang zh` / `--lang en` 在启动时指定。所有界面文案集中在
`i18n.py`，加一种语言只要往一个字典里加一列；`python i18n.py` 会检查两种语言是否
key 一一对应、`%` 占位符是否一致。

**带自动适配的缩放。** 分「仅装置」（默认）、「适配轨迹」、「手动」（0.25x–4x）三种模式；
每个视图按**自己画布的长宽比**算比例，因此不会因为另一个视图装不下而被裁。`+` / `−`
按钮每按一次乘除 1.25。自动模式下读数会分别显示每个视图的实际比例（px/m）。

**实时读数：** `h`、`f_in`、`f_out`、`f_r`、`T_beat`、`x_c`、当前时刻与瞬时 `|x|`、`|y|`，
全部随滑条更新；并在释放振幅超过松弛阈值、两模严格或接近简并、拍周期长到值得调大时间
倍率时给出提示。

## 安装与运行

要求：**Python 3.8 或更新版本，且带 tkinter** —— Windows 与 macOS 的 Python 官方安装包
自带；不少 Linux 发行版需要单独安装（例如 `python3-tk`）。**图形界面本身不需要任何第三方
包。**

matplotlib 只有导出图形与演示脚本才需要；界面里的 `make_figure()` 优先用 matplotlib，
没有时退回 Pillow，所以导出 PNG 至少要装其中一个。

```
python ypendulum_gui.py            # 启动模拟器
python ypendulum_gui.py --lang en  # 以英文启动（也可 --lang zh）
python ypendulum_gui.py --smoke    # 界面自检（需要图形环境），跑完自动退出
```

可选依赖，仅供导出脚本使用：

```
pip install -r requirements.txt    # matplotlib>=3.5
```

## 自检

四条命令，除最后一条外都无需图形环境。当前源码下四条全部通过（Python 3.12.14、
matplotlib 3.11.2）：`I18N: PASS`、`SELFTEST: PASS`、`VERIFY 3D: PASS`、`SMOKE OK`。

```
python i18n.py
```

语言表。两种语言必须定义完全相同的 key 与 `%` 占位符，这样"漏译一半"会在自检里暴露，
而不是在运行时崩掉。通过则打印 `I18N: PASS`。

```
python ypendulum_sim.py --selftest
```

物理。核对参考几何的解析值、三种结点约束状态（三脚架简并到 `1e-9`、滑环与参考值相差
不超过 `2e-3`、系结在无质量结点下相差不超过 `2e-5`）、结点质量的两条预言（`f_in` 不变、
`f_out` 升高）、RK4 积分 60 s 的能量守恒（门限 `1e-3` 相对漂移）、积分频率与解析值的
一致性（门限 `2e-4`）、振幅频移与椭圆积分律的一致性（门限 `5e-4`）、以及 `T_beat` 随振幅
的变化与三个标定值的一致性（门限 `2e-3`）。通过时打印 `SELFTEST: PASS`。

```
python verify_3d.py
```

3D 投影数学，无需图形环境。核对：相机基正交归一且为右手系（4 个视角下最大偏差小于
`1e-12`）；投影与一段**独立写出**的解析透视公式逐点一致（5 个视角 x 27 个点，当前运行
最大偏差 `0` px）；画面中心处的各向同性（数值雅可比奇异值比 `1.0000`，判定门限 `0.95`）；
**56 个视角**下装置都不出界（7 个方位角 x 8 个仰角，装置占画面高度 20%–85%，仰角不低于
20° 时要求至少 40%）；深度单调且尺度与 `1/深度` 成正比；极端视角（`±89.99°`）投影仍有限；
三种结点状态都能投影。脚本还会读取 `ypendulum_gui.py`，确认它检验的正是界面实际使用的
那几个常数。通过时打印 `VERIFY 3D: PASS`。

```
python ypendulum_gui.py --smoke
```

界面，需要图形环境。会建窗、把每个标签页都画一遍并检查各画布确实画出了图元（标签页 1
上侧视、轨迹、包络必须同时绘制）、走一遍参数/滑条路径，然后核对交互：3D 视图的拖动、
滚轮与复位，以及缩放系统 —— `+` / `−` 按钮必须正好改变 1.25 倍，手动缩放必须线性作用到
px/m 系数上（`1.00x` 到 `2.00x` 正好翻倍），两种自动模式在 5 组差别很大的几何（参考、
宽 V 形、短下臂、长下臂、大振幅）下都必须把内容框在画布内。通过时打印 `SMOKE OK`，
失败打印 `SMOKE FAIL: ...`。没有图形环境时会报告无法建窗并以非零码退出。

## 已知限制

1. 动画用的是**有效摆长模型**，不是把每根弦的约束方程逐点数值求解。它复现了两个简正模的
   频率、振幅非线性、模间耦合与结点质量效应，但**不包含**弦的弹性伸缩、结点的快速内部
   振动（约 13.6 Hz）、以及摩擦粘滑。
2. **滑环态是"锚定"而非解析导出的**：该态的面内频率在本模型中没有与几何的解析关系，
   程序按项目文档给出的参考值（`f_r = 1.013574`）锚定，并随 `1/sqrt(L)` 缩放。请把它当作
   "近简并"的定性演示。
3. **振幅超过松弛阈值 `x_c = R*L/h` 后模型不成立**：一根上臂会松弛。程序会告警但仍继续跑
   以供演示，**不要用那段区间的数据下结论**。
4. **界面支持中英双语**：控制面板顶部的 `语言 / Language` 一栏可随时切换，也可以用 `--lang zh` / `--lang en` 在启动时指定；默认跟随系统区域。只有导出的图内标签固定为英文，因为 matplotlib 自带字体不含中文字形。
5. 侧视图把三维运动投影到二维，面外位移看起来会比真实值略小。
